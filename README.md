# ☁️ Skyline Weather

Skyline is a beautiful, dynamic, and fully responsive weather dashboard. Built with a sleek, premium aesthetic in mind, it provides highly detailed meteorological data using free and open APIs.

## ✨ Features

- **Real-time Data**: Current temperature, "feels like" temperature, wind speed, direction, and gusts.
- **Advanced Metrics**: UV Index warnings, Air Quality Index (AQI) with health descriptors, and atmospheric pressure.
- **7-Day Forecast**: Daily max/min temperatures and precipitation probability bars.
- **Interactive Hourly Chart**: A beautifully rendered Chart.js graph plotting the next 12 hours of temperature and rain probability.
- **Dynamic Theming Engine**: Choose from handcrafted premium palettes (Nord, Tokyo Night, Everforest, Rosé Pine, etc.) or pick any hex color to dynamically generate a perfectly matched dark-mode palette.
- **Custom Typography**: Instantly toggle between Montserrat, Inter, JetBrains Mono, and Roboto Mono.
- **Micro-Animations**: Custom CSS animations bring the weather icons to life (floating clouds, spinning suns, falling snow).
- **No API Keys Required**: Powered entirely by [Open-Meteo](https://open-meteo.com/) and [OpenStreetMap](https://openstreetmap.org/), so you can clone and run it instantly.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/1-chezhiyan/skyline-weather.git
   ```
2. Navigate into the directory:
   ```bash
   cd skyline-weather
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser to `http://localhost:5173`.

## 🛠️ Tech Stack

- **Vanilla JS / HTML / CSS**: No heavy UI frameworks. Lightning fast.
- **Vite**: Next-generation frontend tooling for rapid development.
- **Chart.js**: For interactive hourly data visualization.
- **Lucide Icons**: Beautiful, clean SVG icons powered by custom CSS animations.
